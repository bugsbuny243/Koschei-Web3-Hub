# Unified security authority boundaries v1

The unified commercial product does not collapse technical authority.

| Component | Owns | Must not own |
|---|---|---|
| Koschei Web3 Hub | customer security center, entitlement, Web3 orchestration | Lang semantics or Sentinel model promotion |
| ARVIS | evidence collection/normalization, deterministic signed Web3 verdict | unrestricted model-generated authority |
| Koschei Sentinel | evidence-grounded commentary, security reasoning, model evaluation | ARVIS signature/grade mutation or silent production writes |
| Koschei Lang | language semantics, capability model, compiler/runtime, Matrix/policy/proof | ARVIS Web3 evidence authority |

One Professional entitlement and one KOSC token do not imply one trust boundary. Cross-component calls remain explicit, versioned and fail-closed.
