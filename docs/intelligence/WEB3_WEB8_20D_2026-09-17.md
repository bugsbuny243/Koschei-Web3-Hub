## 2026-09-24 fresh intake

### Tezos Quantumnet makes whole-L1 PQ migration testable
Tezos launched Quantumnet on 2026-09-24 as an experimental post-quantum testnet. It activates ML-DSA-44 tz5 accounts and extends PQ experiments beyond account signatures into baking-right randomness, consensus-attestation aggregation and the Data Availability Layer.

**Opportunity:** model PQ readiness as a component graph, not a chain-wide boolean.
**Threat:** wallets/radars can call a chain “quantum safe” after only account signatures migrate while consensus/DAL dependencies remain classical.
**Competitor gap:** evidence object `chain -> component -> algorithm -> network stage -> compatibility -> migration status`.
**Product idea:** PQ migration radar for chains, wallets and infrastructure.

### AINS revision 02 proposes rich agent naming/discovery
`draft-vandemeent-ains-discovery-02` was published 2026-09-24. AINS proposes a transport-independent namespace mapping agent identifiers to identity, capabilities, endpoints, route posture and cryptographic evidence references via HTTPS resolution.

**Opportunity:** ARVIS can ingest agent discovery metadata while preserving the distinction between discovery claims and verified authority/effect evidence.
**Threat:** rich registry metadata can be mistaken for authoritative identity, authorization or trustworthy runtime state.
**Competitor gap:** resolve `agent identifier -> claimed metadata -> evidence reference -> independent verification -> authority -> on-chain effect` rather than trusting registry output.
**Product idea:** agent-resolution provenance adapter with explicit evidence-strength/status fields.

### LFDT opens CLPR cross-ledger protocol work
LF Decentralized Trust announced the new CLPR lab on 2026-09-24. CLPR targets cross-ledger asset/data/message interoperability using state proofs so supported ledgers can verify remote state without depending on a conventional wrapped-asset bridge model.

**Opportunity:** extend cross-chain radar from bridge-message verification to state-proof provenance and remote-ledger verification assumptions.
**Threat:** “state proof” does not eliminate trust; security moves into proof construction, light-client/state-root assumptions, freshness and destination verification.
**Competitor gap:** compare bridge, attestation, burn/mint and state-proof interoperability under one invariant/evidence model.
**Product idea:** cross-ledger verification graph: `source state -> commitment/root -> proof -> verifier assumptions -> destination action -> invariant`.

### QSB optimization sharply lowers an emergency PQ fallback cost
StarkWare's current challenge results reported 2026-09-24 put estimated GPU compute for constructing its experimental Quantum-Safe Bitcoin transaction near $66–67, down from about $320. The construction remains nonstandard for relay, requires direct miner submission and does not make Bitcoin globally quantum-safe.

**Opportunity:** track deployability constraints separately from cryptographic claims and benchmark performance.
**Threat:** “quantum-safe Bitcoin” headlines can overstate a narrow transaction construction as a protocol-wide migration.
**Product idea:** cryptographic-readiness evidence with `scope`, `consensus change`, `relay policy`, `eligible state`, `benchmark vs observed mainnet` distinctions.

## Standards reality
No accepted IETF/W3C generation standard named Web4, Web5, Web6, Web7 or Web8 was identified in the last 24 hours. AINS is an Informational Internet-Draft, not an RFC. Quantumnet is an experimental Tezos testnet. CLPR is a new LFDT open-source lab/protocol effort. QSB is an experimental Bitcoin-compatible construction, not a Bitcoin consensus upgrade.
