Developer API Reference

An API key is a server-side credential only; it never bypasses product authorization. Developer API access requires an active Professional entitlement and a valid API key.

Flow: Koschei account → active Professional entitlement → create API key → server-side X-API-Key request.

Token scan

curl -X POST https://tradepigloball.co/api/v1/scan/token \
  -H "X-API-Key: kos_live_..." \
  -H "Content-Type: application/json" \
  -d '{"mint":"SOLANA_MINT","network":"solana-mainnet"}'

Shield preflight

const response = await fetch('/api/v1/shield/preflight', {
  method: 'POST',
  headers: {'X-API-Key': apiKey, 'Content-Type': 'application/json'},
  body: JSON.stringify({target, intent: 'sign'})
});

Usage

import requests
usage = requests.get(
  'https://tradepigloball.co/api/v1/usage',
  headers={'X-API-Key': api_key}
).json()

Access boundary

Developer API authorization is determined by the active Professional entitlement plus a valid server-side API key. Never embed a raw API key in browser or client-side code.
